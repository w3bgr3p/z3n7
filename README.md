# z3n7

`z3n7` — вспомогательная .NET-библиотека для проектов ZennoPoster.

## Подключение

Скопируйте необходимые DLL библиотеки в папку **ExternalAssemblies** внутри
текущего каталога ZennoPoster.

Видеоинструкция: [подключение внешних сборок в ZennoPoster](https://www.youtube.com/watch?v=Wp6gP_qig_c)
