# Building from source

```bash
dotnet build z3n7/z3n7.csproj -c Release
```

The ZennoPoster assemblies are referenced from the installed ZennoPoster.
The default path is set in `ZennoLab.props`; override it without editing files:

```bash
dotnet build z3n7/z3n7.csproj -c Release /p:ZennoProgs="D:\ZennoPoster\Progs"
```

or set the `ZennoProgs` environment variable.

## Regenerating the API reference

The `API/` folder of this documentation is generated from the source code:

```bash
dotnet run --project tools/DocGen
```

`--check` reports pages that are out of date without writing anything.
