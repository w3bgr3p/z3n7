# База данных

Один API над PostgreSQL и SQLite: класс [[Db]] с явными настройками и помощники `project.Db*`, работающие со строкой текущего аккаунта. См. [[05. База данных]].

| Тип | Что делает |
|---|---|
| [[Db]] | Запросы, чтение, обновление, управление таблицами и колонками, хранение JSON, копирование таблиц между базами. |
| [[Get]], [[DbUpdate]], [[DbSql]] | `DbGet`, `DbGetColumns`, `DbGetLines`, `DbUpd`, `DbInsert`, `DbDone`: строка текущего аккаунта. |
| [[DbTable]], [[DbColumn]], [[DbRange]] | Создание таблиц, добавление/удаление/порядок колонок, заполнение строк аккаунтов. |
| [[DbJson]] | Хранение JSON-объекта в колонках и сборка обратно. |
| [[DbCore]] | `DbQ`: один SQL-запрос к базе из `dbSource`. |
| [[Sql]] | Одно открытое подключение; копирование таблицы и полная миграция между PostgreSQL и SQLite. |
| [[FastDb]] | SQLite через встроенный исполнитель запросов ZennoPoster. |
| [[ProcessManager]], [[TaskManager]] | Таблица `_processes` с запущенными процессами ZennoPoster. |

API: [[Справочник API#Db|Db]], [[Справочник API#DbUtils|DbUtils]]. Исходники: [`Db/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/Db), [`DbUtils/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/DbUtils)
