# Перехват трафика

Чтение того, что браузер отправил и получил.

| Тип | Что делает |
|---|---|
| [[Traffic]] | Запросы, записанные активной вкладкой: `Find` (ждёт), `FindAll`, `GetApiStructure`. |
| [[CdpHar]] | Запись трафика через DevTools браузера и сохранение HAR 1.2; запускать до нужного трафика. |
| [[InstanceExtensions (Traffic)]] | `StartHar`, `SaveHar`, `StopHar`, `GrabTrafficList`. |
| [[HarTraffic]] | HAR из `GetTraffic` и HAR из файла трафика [[Rqst]]. |
| [[ProjectExtensions (Traffic)]] | `SaveSuccessHar`: HAR в папку `har` проекта. |
| [[GraphQL]] | Операции GraphQL, найденные в трафике. |
| [[TrafficCounter]] | Объём трафика по помеченным шагам прогона. |

```csharp
instance.StartHar();
instance.Go("https://example.com");
// ...
instance.SaveHar(Path.Combine(project.Path, "run.har"), urlRegex: "api\\.");
```

API: [[Справочник API#Traffic|Traffic]]. Исходники: [`Traffic/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/Traffic)
