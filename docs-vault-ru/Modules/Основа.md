# Основа

То, с чего начинается большинство скриптов: старт, логирование, переменные, время, секреты.

| Тип | Что делает |
|---|---|
| [[Init]] / [[ProjectExtensions (Essentials)]] | `InitVariables`: старт сессии, диапазон аккаунтов, SAFU, стартовый баннер, встроенный сервер. А также `log`, `warn`, `Age`, `TimeOut`, `Deadline`, `RunZp`. |
| [[Logger]] | Лог с уровнями и полями заголовка, которые включает `cfgLog`. |
| [[Vars]], [[GVars]] | `Var`, `Int`, `Bool`, `VarRnd`, `Range`, `MaxErr`; глобальные переменные и флаги «аккаунт занят». |
| [[Constantes]] | Имя и таблица проекта, пути профилей, `SecureVar`. |
| [[Time]] | Метки времени, кулдауны (`Cd`), секундомеры, случайные паузы. |
| [[SAFU]], [[Z3n8SAFU]] | Шифрование, привязанное к машине, PIN и аккаунту. |
| [[Env]] | Значения из файла `.env`. |
| [[LogDisabler]] | Отключает запись собственных файловых логов ZennoPoster. |

```csharp
project.InitVariables(instance);
project.log("start");                       // в лог проекта
var d = new Time.Deadline();
// ...
d.Check(120);                               // исключение после 120 с
string key = project.ReadEnv("API_KEY");    // .env рядом с проектом
```
