# Браузер

Работа со страницей и инстансом браузера: поиск элементов и клики, ввод текста, JavaScript, cookies, расширения, поиск картинок на скриншоте, настройки отпечатка.

| Тип | Что делает |
|---|---|
| [[InstanceExtensions (Browser)]] | `HeGet`, `HeClick`, `HeSet`, `HeCatch`, `HeDrop`, `HeDragAndDrop`; работа с вкладками и запуском; поиск картинок (`FindImg`, `FindImgFast`, `ClickImg`, `TapImg`), свайпы. |
| [[JsExtensions]] | `JsClick`, `JsSet`, `JsGet`, `JsPost`: то же через JavaScript, включая shadow DOM. |
| [[Cookies]] | Чтение, сохранение и загрузка cookies; JSON ↔ Netscape; cookies в строке аккаунта. |
| [[CookieCollector]] | Сбор свежих cookies с популярных сайтов по HTTP. |
| [[Extension]] | Установка, включение и выключение расширений Chrome. |
| [[GpuSpoof]] | Подбор пары WebGL vendor/renderer той же архитектуры, что видеокарта машины. |
| [[BetterBrowser]] | Профиль браузера под точку выхода прокси и проверка отпечатка. |
| [[BrowserScan]] | Отчёт browserscan.net и исправление часового пояса. |
| [[HtmlExtensions]] | Центр элемента, чтение QR, XPath элемента. |

Элемент задаётся кортежем: `("значение-id", "id")`, `("значение-name", "name")` или `(tag, attribute, pattern, mode, index)`, как в `FindElementByAttribute` ZennoPoster.

```csharp
instance.HeSet(("email", "name"), project.Profile.Email);
instance.HeClick(("button", "innertext", "Continue", "regexp", 0));
string title = instance.HeGet(("h1", "fulltagname", "h1", "regexp", 0));
```

API: [[Справочник API#Browser|Browser]]. Исходники: [`Browser/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/Browser)
