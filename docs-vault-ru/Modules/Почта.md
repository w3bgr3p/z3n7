# Почта

Почтовые ящики для регистраций и одноразовых кодов. Каждый клиент хранит ящик, с которым работает, в переменных проекта (`email`, `mailId` и своя переменная id), чтобы следующий вызов его нашёл.

| Тип | Сервис |
|---|---|
| [[AnyMessage]] | AnyMessage: краткосрочные и долгосрочные ящики на публичных доменах. |
| [[BestMailBox]], [[z3nmail]] | Временные ящики на своих доменах (mail.autoz3n.xyz). |
| [[TempMail]] | Temp Mail (Privatix) через RapidAPI. |
| [[FirstMail]] | FirstMail: ящик, в который приходят пересланные с других адресов письма. |
| [[GmailClient]] | Gmail через Gmail API (OAuth refresh token). |
| [[MSMail]] | Outlook/Hotmail через Microsoft Graph (OAuth refresh token). |

```csharp
var mail = new BestMailBox(project);
var box = mail.NewMail();                 // [id, email]; email также в project.Profile.Email
// ... отправить форму с box[1] ...
string code = mail.Otp(deadline: 90);
```

API: [[Справочник API#Mail|Mail]]. Исходники: [`Mail/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/Mail)
