# Инструменты

Случайные данные, одноразовые коды, изображения и инструменты для файлов проектов ZennoPoster.

| Тип | Что делает |
|---|---|
| [[Rnd]] | Случайные строки, ники, адреса почты, пароли, числа из переменных, паузы. |
| [[Otp]] | TOTP-коды из Base32-секрета; коды из FirstMail. |
| [[Img]] | SVG в PNG. |
| [[Extractor]] | Распаковка и упаковка файлов .zp, поиск текста в их действиях (только в ProjectMaker). |
| [[ZpToCsx]] | Заготовка C#-скрипта из проекта .zp (только в ProjectMaker). |
| [[Helper]] | `project.Help()`: окно-браузер по API. |
| [[Diagnostic]], [[ProjectExtensions (Diagnostic)]] | Версии окружения; отладочные скриншоты с подписью; ошибки из трафика. |

```csharp
string code = z3n7.Tools.Otp.Offline(totpSecret);
project.Profile.Password = Rnd.RndPass();
var hits = project.SearchInZp("ChooseAccountByCondition");   // в ProjectMaker
```
