# Аккаунты

Выбор следующего аккаунта для работы, запуск браузера с его профилем, сохранение и уборка в конце. Весь цикл — в [[06. Работа с аккаунтом]].

| Тип | Что делает |
|---|---|
| [[AccountRunner]] | `ChooseAccountByCondition`, `ChooseAndRunByCondition`, `QuantityByCondition`: выбор аккаунтов по SQL-условию, приоритетам диапазона и фильтрам соцсетей. |
| [[InstanceManager]] | Запуск браузера для `acc0` с папкой профиля, прокси и cookies; сохранение профиля; освобождение аккаунта. |
| [[ProjectExtensions (Accounts)]] | `RunBrowser`, `Finish`, `ReportError`, `ReportSuccess`, `ProxySet`. |
| [[Disposer]] | Конец сессии: отчёт, сохранение, уборка. |
| [[ProfileSync]] | Сохранение и восстановление профиля, настроек инстанса, cookies и WebGL в таблицах `folder_*`, `zb_*`, `zpprofile_*`. |
| [[PropertyManager]] | Перенос простых свойств объекта в строку таблицы и обратно. |

```csharp
if (project.QuantityByCondition("daily < NOW OR daily = ''") == 0) return;
project.ChooseAndRunByCondition(instance, "daily < NOW OR daily = ''", browser: true);
// ...
project.Finish(instance);
```

API: [[Справочник API#Accounts|Accounts]]. Исходники: [`Accounts/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/Accounts)
