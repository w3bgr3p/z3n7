# Встроенный сервер

HTTP-сервер внутри ZennoPoster для оркестратора (DevDeck): состояние задач и команды, логи ZennoPoster, трафик запросов.

```csharp
project.StartZpServer(port: 22222, log: true);   // его же запускает InitVariables
```

При `log: true` печатается строка узла: JSON с машиной, адресом, портом и токеном, который вставляется в DevDeck. Каждый маршрут требует токен (`Authorization: Bearer …` или `?token=`); он хранится как `ZP_TOKEN` в `.env` рядом с `z3n7.dll`.

| Маршрут | Назначение |
|---|---|
| `GET /state` | Задачи и процессы этой машины. |
| `POST /command` | `{ action, task_id, payload }`: старт, стоп, прерывание, попытки, потоки, настройки… |
| `GET/POST /task/xml`, `GET /task/settings` | Настройки задачи. |
| `GET /log` | Файлы логов ZennoPoster. |
| `GET /traffic`, `GET /traffic/har` | Трафик [[Rqst]] страницами JSONL или в HAR. |
| `GET /version` | Версии библиотеки, ZennoPoster и рантайма. |

Типы: [[ZpServer]], [[ZpAuth]]. API: [[Справочник API#Server|Server]]. Исходники: [`Server/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/Server)
