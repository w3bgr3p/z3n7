# Расширения-хелперы

Методы расширения для строк, списков и словарей.

| Тип | Что делает |
|---|---|
| [[StringExtensions]] | Hex ↔ число (с пересчётом в gwei/eth), Base64, «плоский» JSON, диапазоны аккаунтов, экранирование Markdown для Telegram, разбор JWT, пароли. |
| [[ListExtensions]] | `Rnd`: случайный элемент, по желанию с удалением. |
| [[ProjectExtensions (MethodExtensions)]] | Списки ZennoPoster ↔ `List<string>` (`ListSync`, `RndFromList`, `ListFromFile`), `DicToVars`, `ToJson`. |

```csharp
string wei = "0.01".StringToHex("eth");          // 0x2386F26FC10000
string next = project.RndFromList("proxies", remove: true);
```

API: [[Справочник API#MethodExtensions|MethodExtensions]]. Исходники: [`MethodExtensions/`](https://github.com/w3bgr3p/z3n7/tree/master/z3n7/MethodExtensions)
