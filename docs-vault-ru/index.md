# z3n7

z3n7 — вспомогательная библиотека на .NET Framework 4.8 для проектов [ZennoPoster](https://zennolab.com).
Она берёт на себя рутину браузерной автоматизации — подготовку проекта, логирование, HTTP,
базы данных, почтовые ящики, cookies, перехват трафика и отчёты — и выносит её в методы
расширения для `IZennoPosterProjectModel` и `Instance`, чтобы C#-кубики оставались короткими.

## Требования

- ZennoPoster 7.7.21 или новее
- .NET Framework 4.8
