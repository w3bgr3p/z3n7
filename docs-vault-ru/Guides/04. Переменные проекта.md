# Переменные проекта

Большая часть z3n7 читает и пишет переменные проекта ZennoPoster по имени. Проекту, который использует библиотеку, нужны те из перечисленных ниже переменных, которых касаются его вызовы. Отсутствующую переменную [[Vars#Var|project.Var]] пишет в лог и читает как пустую строку.

## Аккаунт и запуск

| Переменная | Назначение |
|---|---|
| `acc0` | Номер текущего аккаунта. Большинство помощников БД читают и пишут «строку текущего аккаунта» именно по нему. |
| `acc0Forced` | Если задана, [[AccountRunner]] берёт этот аккаунт, а не выбирает сам. |
| `cfgAccRange` | Диапазон аккаунтов: `5`, `1-10`, `1,4,7`. Группы через `:` — приоритеты при выборе аккаунта. |
| `rangeStart`, `rangeEnd`, `range` | Заполняются из `cfgAccRange` методом [[Vars#Range\|project.Range()]]. |
| `projectName`, `projectTable` | Имя файла проекта и его таблица `__{имя}`; задают [[Constantes#ProjectName\|ProjectName()]] и [[Constantes#ProjectTable\|ProjectTable()]]. |
| `varSessionId` | Начало сессии, Unix-миллисекунды; задаёт [[ProjectExtensions (Essentials)#StartSession\|StartSession()]]. |
| `err` | Текст последней ошибки; пишут `warn` с `thrw`, [[Vars#MaxErr\|MaxErr]], [[ProjectExtensions (Diagnostic)#CatchErrorFromTraffic\|CatchErrorFromTraffic]]. |
| `lastQuery` | Последнее обновление, записанное через [[DbUpdate#DbUpd\|DbUpd]]; значение с `dropped` помечает сессию как неудачную. |
| `maxErr` | Счётчик ошибок [[Vars#MaxErr\|MaxErr]]. |
| `timeOut` | Предел сессии в минутах для [[ProjectExtensions (Essentials)#TimeOut\|TimeOut()]]. |
| `cfgToDo` | Колонки задач через запятую, которые [[DbTable#TblForProject\|TblForProject]] добавляет в таблицу проекта. |

## Логирование

| Переменная | Назначение |
|---|---|
| `cfgLog` | Подстроки включают поля заголовка лога: `acc`, `time`, `port`, `caller`, `wrap`; `force` отключает фильтр по уровню. См. [[Logger]]. |
| `logLevel` | Минимальный уровень: `Debug`, `Info`, `Warning`, `Error`, `Off`. |
| `debug` | `True` снижает уровень по умолчанию до `Debug`. |

## База данных

| Переменная | Назначение |
|---|---|
| `dbSource` | База для помощников `project.Db*` (переменная проекта, иначе глобальная). Значение, начинающееся с `Host=`, — строка подключения PostgreSQL. См. [[05. База данных]]. |
| `DBmode`, `DBsqltPath` | Режим и файл SQLite для `new Db(project)` и некоторых помощников миграции. |
| `DBpstgrPass` | Пароль PostgreSQL для помощников миграции. |
| `sqlPgHost`, `sqlPgPort`, `sqlPgName`, `sqlPgUser`, `sqlPgPass` | Глобальные переменные: настройки PostgreSQL для `new Db(project)`. |

## Браузер и профиль

| Переменная | Назначение |
|---|---|
| `cfgBrowser` | `Chromium` или `WithoutBrowser`; значение по умолчанию для [[ProjectExtensions (Accounts)#RunBrowser\|RunBrowser]]. |
| `profiles_folder` | Корень хранилища профилей (также хранится как глобальная переменная). |
| `pathProfileFolder`, `pathCookies` | Задаются при запуске браузера: папка профиля аккаунта и файл его cookies. |
| `port`, `pid`, `instancePort` | Порт и PID браузера после запуска. |
| `proxy` | Прокси, который [[Rqst]] берёт для `proxy: "+"`. |
| `headers`, `cookies` | Заголовки (по одному на строку) и cookies (JSON) по умолчанию для [[Rqst]]. |

## Секреты

| Переменная | Назначение |
|---|---|
| `jVars` | Зашифрованный блок настроек; [[Init]] ждёт здесь путь к файлу и загружает его. |
| `cfgPin` | Читается из `jVars` через [[Constantes#SecureVar\|SecureVar]]; PIN шифрования, привязанного к аккаунту ([[SAFU]]). |

Почтовые клиенты хранят своё состояние сами (`email`, `mailId`, `anyMailId`, `tempMailId`, `mailOtp`); см. [[Почта]].
