# Установка

1. Скачай `z3n7.dll` из [последнего релиза](https://github.com/w3bgr3p/z3n7/releases/latest).
2. Положи её в папку `ExternalAssemblies` установленного ZennoPoster.
3. В настройках проекта добавь `z3n7` в директивы using (не в тело C#-кубика).

Видео: [подключение внешних сборок в ZennoPoster](https://www.youtube.com/watch?v=Wp6gP_qig_c)

## Зависимости

Npgsql, AForge.Imaging, System.Net.Http, Svg, ZXing.Net и Otp.NET встроены в `z3n7.dll`
через Costura.Fody — отдельные файлы для них не нужны.

Newtonsoft.Json и HtmlAgilityPack **не** встроены: ZennoPoster должен находить их сам.
