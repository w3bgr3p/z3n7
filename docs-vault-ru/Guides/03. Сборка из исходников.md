# Сборка из исходников

```bash
dotnet build z3n7/z3n7.csproj -c Release
```

Сборки ZennoPoster берутся из установленного ZennoPoster.
Путь по умолчанию задан в `ZennoLab.props`; переопределить его можно без правки файлов:

```bash
dotnet build z3n7/z3n7.csproj -c Release /p:ZennoProgs="D:\ZennoPoster\Progs"
```

или через переменную окружения `ZennoProgs`.

## Обновление справочника API

Папка `API/` этой документации собирается из исходного кода:

```bash
dotnet run --project tools/DocGen
```

С ключом `--check` генератор только сообщает об устаревших страницах и ничего не пишет.
